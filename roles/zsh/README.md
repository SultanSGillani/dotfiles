# zsh role

Builds the zsh environment from scratch: shell config, plugins, theme, completions, aliases, and helper functions.

## What ends up on disk

| Source | Rendered to | Purpose |
|---|---|---|
| `templates/zshrc.zsh.j2` | `~/.zsh/.zshrc` | Main interactive shell config |
| `templates/zshenv.zsh.j2` | `~/.zshenv` | Env vars for *all* zsh invocations (sets `ZDOTDIR`) |
| `templates/zprofile.zsh.j2` | `~/.zsh/.zprofile` | Login-shell extras |
| `files/aliases/*.zsh` | `~/.zsh/aliases/` | Topical alias files (git, docker, kubectl, …) |
| `files/functions/*.zsh` | `~/.zsh/functions/` | Standalone shell functions |
| `files/completions/{osx,debian}/*` | `~/.zsh/completions/` | Static completions chosen by OS |
| `files/{bindings,completions,dir,generic,history,p10k}.zsh` | `~/.zsh/` | Pulled in from `.zshrc` |

`ZDOTDIR` is set to `~/.zsh` in `~/.zshenv`, so zsh sources `.zshrc`/`.zprofile` from there instead of `$HOME` — keeping the home directory clean.

## Plugin manager

[zinit](https://github.com/zdharma-continuum/zinit) is bootstrapped on first run (cloned to `~/.zinit/bin`). Plugin loading uses turbo mode (`zt 0a/0b/0c lucid`) for near-instant prompts. Notable plugins:

- `romkatv/powerlevel10k` — prompt (config in `files/p10k.zsh`)
- `zdharma-continuum/fast-syntax-highlighting` — with `atload"fast-theme default &>/dev/null"` ice so the theme applies *after* the plugin loads (otherwise the theme command isn't defined yet)
- `zsh-users/zsh-autosuggestions` — async, manual rebind for performance
- `zsh-users/zsh-completions`
- `chriskempson/base16-shell` — the theme is set by [base16_builder](../../library/base16_builder.py)

## Order of operations in `.zshrc`

1. **Homebrew shellenv** — must come first so `brew`, `thefuck`, etc. are on PATH for everything that follows.
2. **mise activation** — `eval "$(mise activate zsh)"` ahead of any tool lookups.
3. **PATH composition** — OS-specific lists from [vars/main.yml](vars/main.yml) joined together.
4. **Rust env** — `CARGO_HOME` and `RUST_SRC_PATH` (rust toolchain itself is managed by mise).
5. **zinit + plugins**.
6. **User functions/aliases/completions** sourced last so they can override plugin defaults.

## Things that have caused breakage (and how it's avoided)

- **`exit 1` in `.zshrc`** would kill the interactive shell on a missed dependency. The zinit bootstrap fallback uses `return 1`.
- **`for f in $(ls …)`** breaks on filenames with spaces and errors loudly when the dir is empty. Replaced with `for f in "${ZDOTDIR}"/functions/*.zsh(N)` plus `setopt local_options null_glob`.
- **Bare `[ -zlight $2 ]`** was a typo for an empty-string test. Now `[[ -z "$2" ]] && zinit light …`.
- **`ssh-agent` spawned twice per login**. Now guarded by `[[ -z $SSH_AUTH_SOCK ]]`.
- **Duplicate `MANPAGER`** was set both to `less` (zshenv) and `nvim +Man!` (zprofile). Consolidated to `nvim +Man!` in zshenv only.
- **`fast-theme` chatter** ("Missing style: recursive-base", "Switched to theme `default`") on every shell start. The atload ice now redirects with `&>/dev/null`.

## Updating

After editing any template / file in this role:

```sh
bin/provision zsh
```

Open a new shell (or `exec zsh`) to pick up changes.

## Theme switching

Themes are generated by [`library/base16_builder.py`](../../library/base16_builder.py) and installed by the [base16_builder role](../base16_builder/). The active scheme is set by `base16_theme` in [group_vars/all/main.yml](../../group_vars/all/main.yml).

## Files of interest

- [templates/zshrc.zsh.j2](templates/zshrc.zsh.j2) — the heart of the setup
- [files/p10k.zsh](files/p10k.zsh) — Powerlevel10k prompt config
